# UK-Power-Market-Investment-Model
Build using Python and Excel, this is a quantitative asset valuation model and Monte Carlo risk engine.   This project simulates 25 years of UK electrical price volatility and supply chain inflation. By running simulation cycles, it translates market fluctuations into interpretable financial metrics.






## This project is an Asset-Level Stochastic Financial Risk Valuation Engine
